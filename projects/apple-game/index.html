01 / OVERVIEW

프로젝트 개요

숫자 퍼즐 플레이와 Spring 랭킹 서버 연동을 구현한 Unity 게임입니다.

숫자가 적힌 사과를 영역으로 선택하고 합이 10일 때 제거합니다. 제한 시간 동안 얻은 점수를 랭킹 서버에 보내고 결과를 조회합니다.

02 / FEATURES

주요 기능

01

숫자 그리드

17×10 그리드에 숫자를 배치하고 전체 합의 생성 규칙을 적용합니다.

02

영역 선택과 판정

드래그한 사과 숫자의 합이 10인지 검사하고 점수를 계산합니다.

03

점수와 순위

게임 종료 결과와 별도의 Spring API 서버를 연결합니다.

03 / ENGINEERING

구현에서 선택한 것

판정과 화면 연결

드래그 영역, 선택 해제와 제거·점수 갱신을 게임 흐름으로 연결합니다.

04 / SCOPE

소개 범위

Unity 게임과 랭킹 API 서버는 별도 저장소로 관리됩니다.
