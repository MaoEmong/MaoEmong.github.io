01 / OVERVIEW

어떤 프로젝트인가요?

사람별 기록·약속 관리 서비스에서 다룬 서버 오류 처리와 검증 과정을 정리한 포트폴리오입니다.

음성·텍스트·명함을 사람별 기록으로 모으고, 사용자가 확인한 약속을 달력에 연결하는 서비스입니다. 공개 자료는 전체 서비스 소스 대신 기술적 판단을 확인할 수 있는 독립 예제와 개발 사례에 집중합니다.

역할과 기여

1인 주도로 요구사항과 사용자 시나리오·수정 승인을 담당하고 AI 코딩 에이전트를 분석·구현·테스트 실행에 활용했습니다.

02 / FEATURES

주요 기능

01

사람 중심 기록

기록과 일정을 사람 단위로 모으는 서비스 흐름을 소개합니다.

02

파일 오류의 구분

확정된 파일 부재와 권한·연결·불명확한 저장소 오류를 구분하고, 응답과 부작용을 검사합니다.

03

실행 설정 검사

배포 환경에서 위험한 설정 조합으로 서버가 시작되지 않도록 실제 Spring 실행 문맥을 검사합니다.

  1. 01기록 입력
  2. 02사람별 정리
  3. 03사용자 확인
  4. 04약속·일정
03 / SCREENS

프로젝트 화면

공개 포트폴리오 저장소에 수록된 서비스 소개 화면입니다.

04 / ENGINEERING

구현에서 선택한 것

재현 가능한 독립 예제

실제 서비스·DB·클라우드 계정 없이 Java 21과 Maven으로 예제 검사를 실행할 수 있도록 구성했습니다.

사람과 AI의 역할 구분

요구·판단·AI 지원 작업·검증 결과를 연결하고, 과거 서비스 기록과 현재 예제 검증을 구분합니다.

EVIDENCE & SCOPE

확인한 내용과 소개 범위

공개 저장소에 오류 응답과 실제 Spring 실행 설정을 확인하는 실행 예제, 기술 사례와 AI 협업 근거 문서가 있습니다.

전체 서비스 소스나 원본 개발 이력을 공개한 저장소가 아닙니다. 핵심 AI·검색 구현과 운영 인증 정보는 공개 범위에서 제외했습니다.
