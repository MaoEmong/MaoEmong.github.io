01 / OVERVIEW

어떤 프로젝트인가요?

노트, 지식 그래프, AI 학습카드와 반복 복습을 결합한 팀 학습 플랫폼입니다.

작성한 노트를 연결하고 AI로 학습카드를 생성해 복습으로 이어지는 흐름을 지향합니다. 팀 프로젝트의 여러 서비스와 화면, 설계 결정을 모아 둔 아카이브입니다.

역할과 기여

팀원 표에서 김해준은 플랫폼 서비스의 인증·감사·결제·알림 영역으로 기재되어 있습니다. Flutter 화면은 공동 작업으로 소개됩니다.

02 / FEATURES

주요 기능

01

노트와 연결

마크다운 노트와 위키 링크를 지식 그래프로 연결하는 구조를 다룹니다.

02

학습과 반복 복습

AI 학습카드와 간격 반복 복습, 학습 그룹 공유 흐름을 설계했습니다.

03

여러 서비스의 협력

인증·플랫폼, 지식, 학습, 커뮤니티 기능을 서비스로 나누고 이벤트로 연결하는 구조를 소개합니다.

  1. 01노트 작성
  2. 02지식 연결
  3. 03카드 생성
  4. 04반복 복습
03 / ENGINEERING

구현에서 선택한 것

이벤트로 서비스 연결

Kafka를 통해 각 서비스의 변경을 전달하는 구조와 발행·처리 규칙을 문서화했습니다.

설계 판단 기록

서비스 분리, 통신 방식과 데이터 격리의 선택 이유를 설계 결정 문서로 남겼습니다.
