01 / OVERVIEW

프로젝트 개요

사과게임 클라이언트가 점수를 보내고 랭킹을 조회하는 서버입니다.

점수 저장과 상위 순위 조회에 범위를 좁힌 Spring Boot API 서버입니다. 입력 점수와 조회 개수의 규칙, 동점 정렬 순서를 명시합니다.

02 / FEATURES

주요 기능

01

최고 점수 유지

같은 IP의 기존 점수보다 높은 점수만 저장하고 음수 점수를 제한합니다.

02

예측 가능한 순위

점수·기록 시각·식별자 순서로 정렬하고 서버에서 순위를 부여합니다.

03

조회 범위 제한

기본 10개를 조회하며 요청 개수는 1~100 범위로 보정합니다.

03 / ENGINEERING

구현에서 선택한 것

작은 API 범위

점수 저장과 랭킹 조회의 두 기능에 집중합니다.

클라이언트와 서버 연결

Unity 게임에서 보낸 점수를 DB에 저장하고 정렬한 결과를 반환합니다.

04 / SCOPE

소개 범위

README의 IP 식별 규칙을 소개하는 데모 서버입니다. 인증이나 점수 위변조 방지까지 구현한 것으로 설명하지 않습니다.
