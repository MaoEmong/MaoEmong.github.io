01 / OVERVIEW

어떤 프로젝트인가요?

여러 형식의 문서 검색, DB 조회와 명령 생성 흐름을 결합한 AI 서버입니다.

문서를 검색해 답변에 필요한 자료를 제공하는 RAG 서버입니다. 텍스트 PDF와 스캔 PDF를 구분하고, 필요한 경우 이미지의 글자를 읽어 검색 자료로 만듭니다.

02 / FEATURES

주요 기능

01

여러 문서 형식 지원

PDF, 텍스트, Word와 HTML을 읽어 검색 가능한 자료로 적재합니다.

02

검색과 근거 반환

짧은 단위로 검색하고 원문 문맥을 확장하며, 재정렬한 결과의 출처와 점수를 반환합니다.

03

DB·명령 연결

허용된 DB 조회와 문서 답변을 결합하고, 생성된 명령의 형식을 검사합니다.

  1. 01문서 수집
  2. 02텍스트·OCR 처리
  3. 03검색·재정렬
  4. 04근거 기반 답변
03 / ENGINEERING

구현에서 선택한 것

PDF 종류별 읽기

텍스트 추출과 OCR 처리를 나누어 입력 문서의 차이를 다룹니다.

검색과 문맥 분리

작은 문서 조각으로 찾은 결과를 더 넓은 원문과 연결합니다.

EVIDENCE & SCOPE
