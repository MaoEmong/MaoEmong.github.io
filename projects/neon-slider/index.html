01 / OVERVIEW

어떤 프로젝트인가요?

모바일 스와이프 입력과 타일 스테이지를 구현한 2D 슬라이딩 퍼즐입니다.

손가락 이동 방향을 상하좌우로 판정하고, 관성 이동과 타일 충돌로 퍼즐을 진행합니다. JSON에 정의한 맵과 스테이지 선택 화면을 연결합니다.

02 / FEATURES

주요 기능

01

터치와 이동

스와이프 벡터를 방향으로 변환해 캐릭터를 이동시킵니다.

02

타일 데이터 관리

벽·도착점·시작점·별·부서지는 벽 등 맵 정보를 JSON으로 읽고 저장합니다.

03

스테이지 선택

등록된 스테이지 수에 맞춰 선택 슬롯을 자동 생성합니다.

  1. 01스테이지 선택
  2. 02스와이프 입력
  3. 03이동·충돌
  4. 04목표 도달
03 / SCREENS

프로젝트 화면

공개 README에 수록된 게임 화면입니다.

04 / ENGINEERING

구현에서 선택한 것

맵과 코드 분리

그리드 맵을 데이터로 정의해 스테이지를 구성합니다.

입력과 충돌 연결

터치 이벤트와 물리 충돌을 연결해 이동과 판정을 처리합니다.
