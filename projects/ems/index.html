01 / OVERVIEW

어떤 프로젝트인가요?

사원·조직·근태·휴가부터 데모 급여와 평가까지 관리하는 기업 업무 시스템입니다.

여러 화면과 승인 절차로 나뉘는 인사 업무를 연결했습니다. 기능 구현에 더해 누가 어떤 정보를 볼 수 있는지, 변경 이력이 어떻게 남는지와 AI 결과를 어디까지 적용할지 함께 다룹니다.

역할과 기여

요구사항과 작업 방향을 정하고, Claude Code·Codex의 역할을 나누어 구현·검증을 진행한 AI 협업 프로젝트입니다.

02 / FEATURES

주요 기능

01

조직과 사원 관리

로그인·권한, 사원·부서·직급, 발령·퇴사 이력과 조직도를 관리합니다.

02

근태·급여·평가

근태 정정, 휴가 예약·결재, 월별 데모 급여 생성·확정, 자기·관리자 평가를 연결합니다.

03

AI의 명시적 사용

검색 필터 제안, 확정 평가의 읽기 전용 요약과 합성 규정 Q&A를 제공합니다. 기본 실행은 Mock이며 실제 제공자와 구분합니다.

  1. 01업무 요청
  2. 02권한 확인
  3. 03처리·기록
  4. 04결과 조회
03 / SCREENS

프로젝트 화면

실제 API와 합성 데이터·Mock AI로 촬영한 소개 화면입니다.

04 / ENGINEERING

구현에서 선택한 것

권한 확인을 서버에서

화면 표시뿐 아니라 서버에서도 권한을 확인하고, AI 제공자에게 전달할 정보도 제한합니다.

변경과 확정 결과 보존

감사 기록과 확정된 월별 급여 데이터를 남겨 변경 시점과 결과를 구분합니다.

EVIDENCE & SCOPE

확인한 내용과 소개 범위

README에는 실제 API·MySQL·브라우저를 연결한 검사와 별도 백엔드 검사 결과가 기록되어 있습니다. 이 소개 페이지를 만드는 과정에서 애플리케이션 검사를 다시 실행한 것은 아닙니다.

급여는 데모 규칙이며 제품 AI의 실제 Claude·Ollama 추론은 README상 미실행입니다. 화면은 합성 데이터와 Mock AI로 촬영했습니다.
