01 / OVERVIEW

프로젝트 개요

성장·상점·인벤토리·강화·업적을 구현한 1인 모바일 3D RPG입니다.

탐험과 전투로 보상을 얻고 캐릭터를 성장시키는 흐름을 구현했습니다. 기본 능력치와 추가 능력치, 저장 데이터와 전투·맵 전환을 연결합니다.

역할과 기여

README에 1인 제작 프로젝트로 소개되어 있습니다.

02 / FEATURES

주요 기능

01

캐릭터와 능력치

초기 능력치 생성과 포인트 분배, 기본·가산·합산 능력치를 구분합니다.

02

전투와 적 상태

공격 타이밍과 판정, 적·보스 상태 전환과 연출을 다룹니다.

03

데이터와 게임 진행

JSON 저장·불러오기, 인벤토리·상점, 맵 이동과 캐릭터 복원을 연결합니다.

03 / ENGINEERING

구현에서 선택한 것

기본·추가 능력치 분리

장비·성장에 따른 능력치 계산을 나누어 관리합니다.

상태 기반 적 구현

공통 적 상태 구조를 확장해 일반 몬스터와 보스의 행동을 구성합니다.

04 / SCOPE

소개 범위

RPG의 기본 시스템 구현을 소개하는 프로젝트입니다. 현재 배포·기기별 실행 상태는 별도 확인이 필요합니다.
