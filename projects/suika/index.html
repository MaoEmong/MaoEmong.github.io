01 / OVERVIEW

어떤 프로젝트인가요?

같은 단계의 과일을 충돌시켜 합성하는 2D 퍼즐 프로토타입입니다.

마우스로 위치를 정해 과일을 떨어뜨리고 같은 과일이 만날 때 다음 단계로 합성합니다. 점수와 상단 체류 시간에 따른 게임 종료를 연결합니다.

02 / FEATURES

주요 기능

01

과일 생성과 드롭

상단 대기 과일의 좌우 이동과 클릭으로 떨어뜨리는 조작을 구현했습니다.

02

충돌과 합성

동일 단계 과일의 충돌을 감지하고 다음 단계 과일 생성과 점수 증가를 처리합니다.

03

종료와 초기화

상단 게임오버 라인 체류 시간을 확인하고 메뉴 복귀 시 필드를 정리합니다.

  1. 01위치 선택
  2. 02과일 드롭
  3. 03충돌·합성
  4. 04점수·종료
03 / SCREENS

프로젝트 화면

공개 README의 프로토타입 화면입니다.

04 / ENGINEERING

구현에서 선택한 것

물리 기반 상호작용

2D 물리와 충돌 이벤트로 과일의 움직임과 합성을 연결합니다.

EVIDENCE & SCOPE

확인한 내용과 소개 범위
