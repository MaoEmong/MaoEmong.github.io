BeatTake

주변에서 들은 소리로 그 자리에서 곡을 만들다

생활 소리를 녹음하고 다듬어 여러 트랙에 배치하는 음악 제작 앱입니다. 공개 웹에서 바로 체험할 수 있고 Android 설치 파일도 제공합니다.

01 / CONTEXT

어떤 문제에서 시작했나요?

음악으로 쓰고 싶은 소리는 길을 걷거나 책상 앞에 앉아 있을 때도 들립니다. 휴대폰에서 녹음한 소리를 다른 편집기로 옮기고 트랙을 설정하는 과정은 처음 곡을 만드는 사람에게 부담이 될 수 있습니다.

BeatTake는 주변 소리를 녹음한 뒤 짧은 구간을 다듬고, 같은 앱에서 여러 소리를 겹쳐 곡으로 저장하는 흐름을 제공합니다. 웹에서는 로그인 없이 시작할 수 있습니다.

02 / PRODUCT FLOW

사용자에게 이어지는 흐름

01

녹음과 소리 편집

마이크로 녹음한 원본을 보관하고, 구간과 음 높이를 조절한 소리는 별도 클립으로 저장합니다.

02

트랙 배치와 곡 보관함

클립마다 트랙과 시작 시간을 정합니다. 완성된 배치를 저장한 뒤 곡 보관함에서 다시 재생하거나 편집합니다.

03

선택형 AI 편곡

고른 클립과 분위기를 바탕으로 배치안을 받아 같은 편집 화면에서 수정할 수 있습니다.

한 번의 사용을 따라가 보면

  1. 01

    생활 소리 녹음

    마이크를 허용한 뒤 책상을 두드리는 소리처럼 곡에 쓰고 싶은 소리를 녹음합니다.

  2. 02

    클립 다듬기

    원하는 구간과 음 높이를 정해 미리 듣고, 이름을 붙여 클립으로 저장합니다.

  3. 03

    곡 배치

    소리마다 트랙과 시작 시간을 정합니다. 여러 소리가 겹치는 구간도 함께 들어볼 수 있습니다.

  4. 04

    저장하고 다시 열기

    곡 보관함에서 완성한 배치를 다시 재생하거나 편집합니다. AI의 배치안도 같은 편집 화면에서 손볼 수 있습니다.

03 / ARCHITECTURE

구조와 책임을 나눈 방식

  1. 01

    Flutter 화면

    녹음과 편집, 트랙 배치, 곡 보관함 화면을 Flutter로 구성해 웹과 Android에서 사용합니다.

  2. 02

    기기에서 편집하고 저장

    녹음과 클립을 WAV로 다룹니다. Android에서는 기기 파일, 웹에서는 브라우저 저장소에 기록하며 재생할 때 소리를 기기 안에서 합칩니다.

  3. 03

    선택형 OpenAI 편곡

    고른 클립의 이름과 길이, 원하는 분위기를 OpenAI에 보내 트랙 번호와 시작 시간을 받습니다. 앱이 배치를 확인해 곡 편집 화면에 엽니다.

04 / ENGINEERING CASES

구현하면서 선택한 것

기능 목록 뒤에 있는 문제와 선택, 그 선택이 남긴 비용을 정리했습니다.

CASE 01

빠르게 두 번 저장해도 곡은 한 번만 저장

마주한 문제
독립 검토에서 저장 버튼을 빠르게 두 번 누르면 곡이 중복 저장되는 상황을 재현했습니다.
선택과 구현
저장이 진행되는 동안 두 번째 요청을 막았습니다. 같은 조작을 반복해도 곡 한 개만 저장되고 보관함으로 돌아오는지 자동 테스트로 확인했습니다.
남은 비용과 한계
저장 작업이 끝날 때까지 다음 저장을 기다립니다.
중복 저장 테스트 ↗
CASE 02

원본과 다듬은 소리를 따로 보관

마주한 문제
곡에 맞춰 구간을 자르거나 음 높이를 바꾼 뒤에도 다른 편집에 원래 소리가 필요할 수 있습니다.
선택과 구현
원본 녹음과 편집한 클립을 따로 저장합니다. 곡에는 사용할 클립과 트랙, 시작 시간을 저장해 곡을 다시 열어 배치를 바꿀 수 있게 했습니다.
남은 비용과 한계
녹음과 편집본을 각각 보관하므로 기기 저장 공간을 사용합니다.
곡과 배치 구조 ↗
CASE 03

AI가 만든 배치를 확인하고 편집 화면에 열기

마주한 문제
AI가 제안한 배치에 선택 범위를 벗어난 클립이나 허용 범위를 벗어난 시간이 들어갈 수 있습니다.
선택과 구현
선택한 소리만 배치하도록 요청하고 응답의 소리 ID, 트랙, 시간과 곡 길이를 확인합니다. 사용자는 같은 편집 화면에서 결과를 수정하고 저장할 수 있습니다.
남은 비용과 한계
AI 편곡에는 네트워크와 개인 OpenAI API 키가 필요합니다. 웹에서 키는 현재 페이지가 열려 있는 동안 사용합니다.
AI 편곡 요청과 응답 검사 ↗
05 / ROLE & CONTRIBUTION

맡은 역할과 기여

개인 프로젝트로 녹음에서 편집과 곡 보관까지의 화면 흐름을 정했고, Track Lens 디자인을 골라 한국어를 포함한 네 언어를 지원하도록 구성했습니다.

Codex를 구현과 검증에 활용했습니다. 별도 검토에서 중복 저장을 재현해 수정했고, 실제 편곡을 받아 저장·재생하는 과정이 확인된 OpenAI로 출품 범위를 정했습니다.

06 / EVIDENCE & LIMITS

무엇을 확인했고, 무엇이 남았나요?

프로젝트 검증 당시의 실행 기록과 코드에 구성한 테스트 항목을 정리했습니다. 각 항목에 실행 조건과 추가 확인이 필요한 범위를 함께 적었습니다.

공개 웹에서 녹음부터 다시 재생까지

Chrome에서 녹음한 소리로 곡을 저장하고 페이지를 다시 열어 재생했습니다. 실제 OpenAI 결과도 트랙 편집 화면에서 재생하고 저장했습니다.

기존 공개 웹 검증 기록입니다. 이 페이지의 한국어 화면은 휴대폰 크기의 Chrome에서 시험용 소리로 촬영했습니다.

검증 근거 보기 ↗

Android 설치와 자동 테스트

Android 15 가상 기기에 APK를 설치하고 녹음과 편집을 확인했습니다. 자동 테스트 16개가 통과했고 공개 APK가 검증한 설치 파일과 같은지 확인했습니다.

가상 기기와 공개 파일을 기준으로 확인했습니다.

검증 근거 보기 ↗

현재 범위와 남은 과제

  • 수동 편집과 곡 만들기는 로그인이나 API 키 없이 쓸 수 있습니다. AI 편곡에는 개인 OpenAI API 키와 인터넷 연결이 필요합니다.
  • 웹 녹음과 곡은 사용한 브라우저에 저장됩니다. 실제 휴대폰과 모바일 브라우저를 넓게 검증하는 작업은 남아 있습니다.

다음에 보완할 것

  • 완성한 곡을 WAV 파일로 내보내 공유하거나 다른 음악 앱에서 열 수 있도록 확장합니다.
  • 더 다양한 휴대폰에서 마이크 권한, 녹음 중단과 재생을 확인합니다.
