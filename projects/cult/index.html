01 / OVERVIEW

어떤 프로젝트인가요?

5인 팀이 3주 동안 제작한 액션 어드벤처 모작입니다.

4개 스테이지와 보스전으로 이루어진 교육·연습 목적의 팀 프로젝트입니다. 본인 담당 범위는 타이틀·로딩·화면 UI·필드 오브젝트와 씬·스테이지 전환입니다.

역할과 기여

타이틀·로딩 씬, 필드 오브젝트·UGUI 화면과 씬·스테이지 전환 시스템을 담당했습니다.

02 / FEATURES

주요 기능

01

타이틀과 로딩

메뉴, 새 게임·계속하기, 비동기 로딩 진행도와 팁을 구성했습니다.

02

화면과 필드 오브젝트

HP·스킬·미니맵·팝업 UI와 상호작용·트랩 오브젝트를 제작했습니다.

03

진행과 씬 전환

클리어·포탈·게이트 조건에 따라 스테이지를 바꾸고 로딩 씬으로 연결합니다.

  1. 01타이틀
  2. 02로딩
  3. 03스테이지 진행
  4. 04보스전
03 / SCREENS

프로젝트 화면

공개 README에 수록된 교육용 모작 화면입니다.

04 / ENGINEERING

구현에서 선택한 것

씬과 스테이지 구분

장면 전환과 진행 조건을 구분해 게임 흐름을 관리했습니다.

반복 오브젝트 재사용

상호작용 가능한 필드 오브젝트를 프리팹으로 구성했습니다.

EVIDENCE & SCOPE

교육·연습 목적의 모작이며 전체 팀의 결과와 본인 담당 영역을 구분합니다.
