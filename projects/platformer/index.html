01 / OVERVIEW

프로젝트 개요

이동·점프·적 회피·점수 획득을 연결한 3스테이지 플랫포머입니다.

PC 키보드 조작을 사용하는 짧은 2D 어드벤처입니다. 타일맵으로 레벨을 만들고, 공통 적 클래스와 재사용 가능한 오브젝트로 월드를 구성했습니다.

02 / FEATURES

주요 기능

01

타일맵 레벨

Tilemap과 충돌 정보를 사용해 3개 스테이지를 구성했습니다.

02

공통 적 구조

적의 이동·피해·사망 처리를 공통 클래스에 두고 종류별로 확장합니다.

03

월드 오브젝트

몬스터·세이브포인트·도착점·코인 등의 오브젝트를 재사용 가능한 단위로 만듭니다.

03 / ENGINEERING

구현에서 선택한 것

공통 동작과 확장 분리

EnemyBase에서 공통 기능을 제공하고 적 종류별 동작을 확장합니다.

04 / SCOPE
