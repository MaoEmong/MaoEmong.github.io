01 / OVERVIEW

어떤 프로젝트인가요?

상품 탐색과 주문·결제·환불·배송·반품, 관리자 운영을 연결한 단일 판매자 쇼핑몰입니다.

고객과 관리자 화면을 하나의 React 앱으로 구성하고, Spring Boot 서버 안에서 업무별 영역을 나눴습니다. 요청이 겹치거나 처리 결과를 바로 확인할 수 없을 때도 주문·재고·환불 상태를 복구하는 흐름에 집중했습니다.

역할과 기여

개인 프로젝트로 요구사항과 작업 방향을 정하고, 픽셀 오피스에서 Claude Code·Codex의 구현·검증을 관리했습니다.

02 / FEATURES

주요 기능

01

고객의 구매 흐름

검색·조건별 탐색, 색상·크기별 상품 선택, 장바구니와 주문·취소·반품을 연결합니다.

02

관리자의 운영 흐름

상품·재고·입고·배송·반품 승인과 결과 확인이 필요한 결제·환불 요청을 관리합니다.

03

AI 기능의 적용 경계

자연어 상품 검색과 상품 설명 초안을 제공합니다. 현재는 모의 응답이며 설명 초안은 담당자가 승인합니다.

  1. 01상품 탐색
  2. 02주문·결제
  3. 03배송·취소
  4. 04반품·환불
03 / SCREENS

프로젝트 화면

공개본을 로컬에서 실행한 고객 화면입니다. 상품 이미지는 AI로 만든 소개용 예시이며 실제 상품 사진이 아닙니다.

04 / ENGINEERING

구현에서 선택한 것

중복 처리와 불확실한 결과 대응

같은 요청의 식별값을 보존해 재시도하며, 결제 결과가 늦게 도착해도 중복 처리되지 않도록 상태를 확인합니다.

돈과 물품의 흐름 분리

환불 결과와 반품 물품의 수령·재고 복원을 따로 관리합니다. 재고 예약은 만료와 복원이 한 번씩 처리되도록 구성했습니다.

EVIDENCE & SCOPE

확인한 내용과 소개 범위

공개본 기록: 화면 단위 검사 319개, 서버 단위 검사 40개 통과와 새 DB 기동 확인. 서버 통합 검사 33개 클래스는 공개본에서 재실행하지 않았습니다.

실제 결제사·AI 모델과 외부 배포는 미연결입니다. 결제·AI는 모의 응답이며, 상품 이미지는 AI로 만든 예시입니다. 이 소개 작성 중 앱 검사를 다시 실행하지 않았습니다.
