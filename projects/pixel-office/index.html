01 / OVERVIEW

어떤 프로젝트인가요?

Claude Code·Codex의 대화, 회의, 작업 배정과 진행 상태를 관리하는 Windows 앱입니다.

여러 AI 터미널을 번갈아 확인하는 대신, 누가 무엇을 하고 누구를 기다리는지 한 화면에서 살펴봅니다. 부장에게 목표를 전달하면 팀을 구성하고, 단계별 결과와 필요한 승인을 확인할 수 있습니다.

역할과 기여

제품 목표와 실제 사용 중 문제, 기대 동작을 제시하고 AI 지원으로 구현·검증·배포를 진행했습니다. 이 앱을 사용해 EMS를 제작했습니다.

02 / FEATURES

주요 기능

01

대화와 단계 기록

사용자의 요청과 부장의 답변, 팀장 회의, 작업 계획과 단계별 결과를 구분해 보여 줍니다.

02

질문·보고 대상 구분

팀원은 팀장에게, 팀장은 부장에게, 부장은 사용자에게 보고합니다. 사용자 판단이 필요한 질문과 실행 승인은 별도로 표시합니다.

03

연결 복구와 이미지 입력

로그인·실행 오류를 팝업으로 안내하고 기존 작업의 복구를 시도합니다. 이미지 첨부, 붙여넣기와 확대 보기를 지원합니다.

  1. 01목표 정리
  2. 02팀 구성·회의
  3. 03배정·실행
  4. 04검토·단계 기록
03 / SCREENS

프로젝트 화면

실제 Windows 앱에 소개용 예시 데이터를 넣은 화면이며 실제 AI 작업 결과나 계정 정보가 아닙니다.

04 / ENGINEERING

구현에서 선택한 것

실제 AI 세션 연결

Flutter 화면과 Node.js 실행 관리 프로그램을 분리하고, 실제 Claude Code·Codex 명령 프로그램을 연결합니다.

실패를 사용자에게 설명

일반 대기와 오류를 구분하고, 누구를 왜 기다리는지와 필요한 복구 조치를 표시합니다.

EVIDENCE & SCOPE

확인한 내용과 소개 범위

공개 검증 기록의 Windows 압축 해제본 실행·복구 검사 9개와 파일 1,935개 대조를 확인할 수 있습니다. 같은 PC에서 사용자 데이터와 실행 경로를 분리한 검사입니다.

Windows 0.1.0 시험판입니다. 다른 PC와 실제 계정 조합별 장시간 검증은 남아 있으며, 앱 원본 개발 코드는 비공개입니다.
