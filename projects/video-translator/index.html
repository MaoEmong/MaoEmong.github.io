PROJECT 07 AI·검색

Video Translator

01 / OVERVIEW

어떤 프로젝트인가요?

영상 업로드부터 음성 인식·번역·자막 다운로드까지 처리하는 서비스입니다.

영상의 음성을 인식하고 번역한 뒤, 시간 정보가 유지되는 SRT·VTT 자막으로 제공합니다. 오래 걸리는 미디어 처리와 외부 AI 응답을 작업 단계로 나누어 관리합니다.

02 / FEATURES

주요 기능

01

비동기 영상 처리

Object Storage로 영상을 올리고 Redis 작업 큐로 음성 추출과 후속 처리를 수행합니다.

02

음성 인식과 번역

FFmpeg로 오디오를 정리하고 Whisper 음성 인식과 구조화된 번역 응답을 사용합니다.

03

편집과 내려받기

번역문·표시 시간 편집, 번역 버전 관리와 SRT·VTT 내보내기를 제공합니다.

  1. 01영상 업로드
  2. 02음성 인식
  3. 03번역·편집
  4. 04자막 내보내기
03 / ENGINEERING

구현에서 선택한 것

API와 작업 처리 분리

오래 걸리는 작업을 별도 처리기로 보내 상태와 진행률을 조회하도록 구성했습니다.

외부 응답 검증

AI 응답 구조를 확인하고 제공자 오류를 서비스가 다루는 오류로 구분합니다.

EVIDENCE & SCOPE
