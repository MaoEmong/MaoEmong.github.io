01 / OVERVIEW

어떤 프로젝트인가요?

기기에서 위치 흐름을 수집해 하루의 이동 경로와 머문 곳을 정리하는 앱입니다.

사용자가 매번 기록하지 않아도 하루의 흐름을 돌아볼 수 있게 만드는 앱입니다. 지도 자체보다 날짜별 기록, 이동과 머문 곳을 읽기 쉽게 정리하는 경험에 집중합니다.

02 / FEATURES

주요 기능

01

자동 위치 기록

Android의 백그라운드 위치 기록과 권한·알림 설정을 다룹니다.

02

하루 단위 돌아보기

오늘의 기록, 이동 경로 재생, 날짜별 요약과 상세 화면을 제공합니다.

03

장소와 로컬 데이터

부정확한 좌표를 걸러 내고 머문 곳 후보를 정리합니다. 사용자가 저장한 장소와 SQLite 데이터를 관리합니다.

  1. 01위치 수집
  2. 02좌표 정리
  3. 03하루 요약
  4. 04기록 돌아보기
03 / SCREENS

프로젝트 화면

README에 수록된 데모 데이터 화면입니다.

04 / ENGINEERING

구현에서 선택한 것

원본과 표시 데이터 분리

원본 좌표와 화면에 표시하는 경로·장소 정보를 구분해 처리합니다.

화면별 비동기 상태 분리

오늘 화면과 상세 정보의 상태를 나누어 하나의 조회가 화면 전체를 막지 않게 구성했습니다.

EVIDENCE & SCOPE

확인한 내용과 소개 범위

README에 코드 검사·테스트 명령과 실제 Android 기기에서 확인할 체크리스트가 있습니다.

장시간 위치 기록 안정성, 좌표 후처리와 릴리스 서명 등은 README의 남은 과제에 포함됩니다.
